How to Run This Lab
1. Clone this repository on Frontier.
       a. Open a browser and go to https://jupyter.olcf.ornl.gov
       b. Log in with your csep*** username and PIN + token code.
       c. Select the CPU Workloads instance.
       d. Once it starts, click on the Terminal icon.
       e. From the terminal, cut and paste the following command:
              git clone https://github.com/suzannepk/K_means.git
2. In the left-column menu, click on K-Means.ipynb to open the notebook.
3. Follow the directions in the notebook to complete the challenge.
4. The last step will ask you to fill out this Google Form, https://forms.gle/SkC54qf6H8Gati6B7 with your observations from the challenge.
